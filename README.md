# Profile and Contact Page

## Project Description

This project is a single-page personal profile and contact webpage built using HTML5 and CSS.

It introduces the website owner, displays personal interests and goals, and provides a contact form for visitors.

## Features

* Semantic HTML5 structure using `header`, `nav`, `main`, `article`, `section`, and `footer`.
* About Me section with a profile picture and alternative text.
* Ordered and unordered lists.
* Contact form with full name, email, inquiry category, and message fields.
* Newsletter subscription checkbox.
* Form validation using HTML attributes.
* Responsive styling for smaller screens.
* Keyboard accessibility features.

## Technologies Used

* HTML5
* CSS3

## Project Files

* `index.html` — contains the webpage structure, styling, and contact form.
* `profile.jpg.jpeg` — profile image used on the webpage.

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Ensure the profile image is in the same folder as `index.html`.
